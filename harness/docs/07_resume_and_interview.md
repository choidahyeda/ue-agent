# 경력 기술 초안과 면접 준비

## 경력 요약

- 게임 엔진: 언리얼 C++, Blueprint (Fluxity)
- 3D 파이프라인 + Python: NVIDIA Omniverse (씨이랩)
- AI API 실서비스: GPT API 기반 용어 검수 도구 (넥슨)
- 툴 설계: 확장 가능한 인터페이스, Blueprint용 C++ API 설계 (Fluxity)

## 경력 기술 초안

### 마비노기 전용 용어 검수 도구 개발 (넥슨, C#)
- 기획, 시나리오 작성 및 아이템 명명 시 사용하는 게임 전용 맞춤법, 용어 검수 도구 설계 및 개발
- 게임 표기 규칙(예: '대미지' 대신 '데미지', '랜덤 확률' 대신 정확한 수치 표기)을 반영한 게임 전용 단어 사전 구축
- 3단계 검수 파이프라인 설계
  - 1차: Aho-Corasick 기반 정규화 및 다중 패턴 동시 매칭으로 금지어, 규칙 위반 표현 탐지
  - 2차: BK-Tree 기반 편집 거리 탐색으로 오탈자 의심 단어 추출
  - 3차: GPT API로 띄어쓰기, 오탈자 문맥 검토 및 교정 문구 제안
- 규칙 기반 처리로 확정 가능한 케이스를 먼저 걸러 LLM 호출을 최소화하고, 모델 판단은 문맥 검토에 한정해 결과 일관성 확보
- (채울 것) 툴 형태, 사용 인원, 검수 시간 단축 등 효과 수치

### MQTT 기반 실시간 모니터링 시스템 (Fluxity, 언리얼 C++, Blueprint)
- UObject 기반 추상 저장소 인터페이스(UMQTTExternalStorageProvider) 설계, 외부 DB 스펙 확정 전 확장 가능한 구조 확보
- Blueprint에서 쓰기 쉬운 C++ API 설계
- 게임 스레드 마샬링 확인 후 뮤텍스 대신 계약 기반 검증(ensureAlwaysMsgf) 선택

### Omniverse Python 개발 (씨이랩)
- Python으로 NVIDIA Omniverse(USD 기반 3D 플랫폼) 코드 작업
- 이력서에서는 짧게, "3D 플랫폼을 Python으로 다룬 경험"으로 배치

### 포트폴리오: TA 에셋 및 성능 예산 검수 에이전트 킷 (Python, UE 5.8)

## 예상 면접 질문

### 넥슨 검수기
- 왜 전부 GPT로 처리하지 않고 3단계로 나눴는지
- Aho-Corasick과 BK-Tree를 고른 이유 (한 번 순회로 다중 패턴 탐색, 편집 거리 기반 유사어 탐색)
- GPT가 틀린 교정을 제안하거나 게임 용어를 오탈자로 고치려 할 때 어떻게 막았는지
- 프롬프트 구성 (사전 규칙이나 1, 2차 결과를 같이 넘겼는지)

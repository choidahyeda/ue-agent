# 하네스: TA 에셋 및 성능 예산 검수 에이전트 킷

크로노스튜디오 TA팀 "AI 개발 자동화 엔지니어" 지원용 포트폴리오를 AI 에이전트와 함께 만들기 위한 작업 하네스입니다.

## 사용법

1. Claude Code(또는 Codex)를 이 폴더가 들어 있는 프로젝트 루트에서 실행
2. 첫 메시지: "하네스 읽고 오늘 작업 시작해"
3. 에이전트가 `CLAUDE.md` 규칙에 따라 현황판과 최근 로그를 읽고 다음 태스크를 진행
4. 작업이 끝나면 "오늘 작업 마무리해" 라고 하면 현황판과 날짜별 로그가 갱신됨

## 사람이 주로 볼 파일

- `status/TASKS.md` : 지금 뭐가 남았는지 한눈에
- `logs/` : 날짜별로 무엇을 했는지
- `status/DECISIONS.md` : 왜 이렇게 만들었는지 (면접 준비에도 활용)

## 한 줄 목표

아트, 코드 부서가 만든 에셋과 코드를 **저장소에 들어가기 전에** 스튜디오 규칙과 성능 예산으로 검사하고,
위반 이유와 수정 방법을 AI가 설명해주는 도구를 공식 언리얼 MCP(UE 5.8) 위에 만든다.

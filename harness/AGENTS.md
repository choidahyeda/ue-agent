# AGENTS.md

Codex 등 AGENTS.md를 읽는 에이전트용 진입점입니다.
작업 규칙은 `CLAUDE.md` 와 동일합니다. 반드시 `CLAUDE.md` 를 먼저 읽고 그 규칙을 따르세요.

요약:
1. 시작 시 `CLAUDE.md` → `status/TASKS.md` → 최근 `logs/` → 관련 `docs/`, `specs/` 순서로 읽기
2. 한 번에 한 태스크, 규칙 값은 `specs/asset_rules.yaml` 에서만 읽기
3. 종료 시 `status/TASKS.md` 갱신, `logs/YYYY-MM-DD.md` 작성, 필요하면 `status/DECISIONS.md` 기록
